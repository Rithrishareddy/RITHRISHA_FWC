\noindent\textbf{Abstract} \\[0.5em]
This project implements and verifies a logic function derived from a GATE 2008 Karnaugh map (K-map) question using a Raspberry Pi Pico and basic components such as push buttons and an LED. The function is realized in hardware and validated through practical observation.

\vspace{1em}
\noindent\textbf{1. Question and Options}
\begin{itemize}
  \item[(A)] QS + PRS + PQR + PRS + PQR
  \item[(B)] QS + PRS + PQR + PRS + PQR
  \item[(C)] PRS + PQR + PRS + PQR
  \item[(D)] PRS + PQR + PRS + PQR
\end{itemize}
\textbf{Correct Answer: (A)}

\vspace{1em}
\noindent\textbf{2. Explanation and Simplification}
\begin{itemize}
    \item Group RS = 01 with PQ = 00, 01, 11 $\rightarrow$ QS
    \item Group PQ = 01, RS = 11, 10 $\rightarrow$ PRS
    \item Group PQ = 01 and 11 with RS = 01 $\rightarrow$ PQR
    \item Group PQ = 11, RS = 01, 11 $\rightarrow$ PRS
    \item Group PQ = 11 with RS = 01 $\rightarrow$ PQR
\end{itemize}
\[
f = QS + PRS + PQR + PRS + PQR
\]

\noindent\textbf{4. Setup and Connections}
\begin{itemize}
    \item Connect P to GP14, Q to GP15, R to GP16, and S to GP17.
    \item Connect the output LED to GP13 with a 220$\Omega$ resistor.
    \item Use 10k$\Omega$ pull-down resistors for each button input.
    \item Connect 3.3V and GND from the Pico board.
\end{itemize}

\vspace{1em}
\noindent\textbf{5. Logic Summary}
\begin{itemize}
    \item Inputs: P, Q, R, S (pressed = 1)
    \item Logic Expression: $f = QS + PRS + PQR + PRS + PQR$
    \item Output f is HIGH (LED ON) when expression evaluates to 1
\end{itemize}

\vspace{1em}

    \item \textbf{R} – GP16 (Input)
    \item \textbf{S} – GP17 (Input)
    \item \textbf{LED (f)} – GP13 (Output)
\end{itemize}

\noindent\textbf{9. Procedure to Upload Code (Pico2W)}
\begin{enumerate}
    \item Connect Pico 2W to USB while holding BOOTSEL.
    \item Drag and drop MicroPython firmware to mount as drive.

    \item Run and validate logic using LED for different input conditions.
\end{enumerate}
