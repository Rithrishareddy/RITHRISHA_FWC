\noindent
\textbf{Q.36} \\
If \(X = 1\) in the logic equation
\[
\left[X + Z \left\{\overline{Y} + \left(\overline{Z} + X\overline{Y}\right)\right\}\right]
\left[\overline{X} + \overline{Z} \left(X + Y\right)\right] = 1,
\]
then
\begin{enumerate}
    \item[(A)] \(Y = Z\)
    \item[(B)] \(Y = \overline{Z}\)
    \item[(C)] \(Z = 1\)
    \item[(D)] \(Z = 0\)
\end{enumerate}

\noindent
\textbf{Answer: (C) \(Z = 1\)} \\

\noindent
\textbf{Explanation:} \\
Given \(X = 1\), the expression simplifies as follows:
\[
\left[1 + Z\left(\overline{Y} + (\overline{Z} + \overline{Y})\right)\right]
\left[0 + \overline{Z}(1 + Y)\right] = 1
\]
Simplify the inner terms:
\[
\overline{Y} + (\overline{Z} + \overline{Y}) = \overline{Y} + \overline{Z}
\]
So,
\[
\left[1 + Z(\overline{Y} + \overline{Z})\right]
\left[\overline{Z}(1 + Y)\right] = 1
\]
The first term is always \(1\) (since \(1 +\) anything = 1). So we only need:
\[
\overline{Z}(1 + Y) = 1
\]
For this to be \(1\), \(\overline{Z} = 1\) which means \(Z = 0\). But wait—since \(\overline{Z}(1 + Y)\) is supposed to be  \(1\), let's analyze carefully:

- \(\overline{Z} = 1 \implies Z = 0\)
- Then \((1 + Y)\) must be \(1\) (always true), so \(\overline{Z}(1 + Y) = 1\).

 However, the given answer (C) says \(Z = 1\). Let’s double-check:

- If \(Z = 1\):
  - Then \(\overline{Z} = 0\).
  - So \(\overline{Z}(1 + Y) = 0\).
  - Then the second term = 0.
  - But that would make the entire product \(0\), contradicting the equation.

If \(Z = 0\):
- Then \(\overline{Z} = 1\).
- Then \(\overline{Z}(1 + Y) = 1\).
- Then the product is \(1 \cdot 1 = 1\).

Hence the correct answer is:
\[
\boxed{(D) \ Z = 0}
\]

Thus, the answer is actually (D).

\noindent
\textbf{Corrected Answer: (D) \(Z = 0\)}
